# Forge Project Skill Guide

This repository uses custom workflow docs to describe how to develop, test, and publish changes to Forge.

## Files

- `DEVELOPMENT.SKILL.md` — coding and implementation workflow
- `TESTING.SKILL.md` — unit/integration test guidance and verification steps
- `PUBLISHING.SKILL.md` — commit, PR, and review workflow

## Purpose

These files are intended for maintainers and contributors to follow a consistent process:

- keep feature work small and focused
- validate with automated tests before pushing
- use conventional commits
- add docs for UX or configuration changes
